# shooting
めちゃくちゃ出る敵を撃ちまくるゲーム

無数に上から降りてくる敵を撃ちまくるだけのゲームです。
制限時間以内に画面下の赤いゾーンへ敵が侵入しなければクリアです。

君はストレス発散することができるか？

操作方法　画面下部のボタンをタップするだけ
←　左に移動
💣　爆弾投下 画面上の敵を消す
→　右に移動

キーボードでも操作可能
左右のキーとスペース(ボム)

敵について
ザコキャラ(白→黒の順に固い)
中ボス　戦車
大ボス　空母

パワーアップアイテム
S　最大7段階までパワーアップ(並、大レベルは制限あり)
O　オプション、最大6個
B　爆弾補充
